Телефонная книга, сравнение строк, манглинг имён функций

examples/phonebook.keel — прикладной пример: книга в памяти, добавление,
поиск (по id и по имени), правка, удаление, чтение. Главное в нём — что
компилятор ловит устаревшую ссылку: взяли ссылку на запись, запись
перезаписали, ссылка стала недействительной. В C это тихая ошибка.

Строки теперь сравниваются по содержимому, а не по адресу: для == и !=
эмитится strcmp. Раньше сравнение строк в C было сравнением указателей,
то есть работало случайно.

Имена пользовательских функций получают префикс k_ в C. Без этого любая
функция, названная как функция стандартной библиотеки (remove из stdio.h,
index из strings.h), приводила к конфликту типов. main остаётся как есть.
