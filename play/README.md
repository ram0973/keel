# Keel — туториал

Пошаговое введение в язык. Каждый файл — **рабочая программа**:
читайте сверху вниз и запускайте. Всё, что написано в комментариях,
компилятор действительно делает.

## Запуск

```sh
cd ~/keel
cargo build                       # один раз

./target/debug/keelc run play/01-basics.keel
```

Проверить, не запуская:

```sh
./target/debug/keelc check play/01-basics.keel
```

Собрать в отдельный файл — останутся и бинарник, и C-исходник:

```sh
./target/debug/keelc compile play/01-basics.keel /tmp/basics
```

## Порядок чтения

Файлы идут по возрастанию сложности. Каждый следующий опирается
на предыдущие.

| # | Файл | О чём |
|---|---|---|
| 1 | `01-basics.keel` | переменные, `let`/`let mut`, три типа, печать, арифметика, комментарии, `const`, **ввод и аргументы командной строки** |
| 2 | `02-control-flow.keel` | `if`/`else`, логика, `if` как выражение, `while`, `do-while`, `for` по диапазону и по массиву, `break`/`continue` |
| 3 | `03-functions-structs.keel` | функции, `return`/`return;`, рекурсия, структуры, массивы, методы, `self` как параметр, `mut(self)`, ассоциированные функции и `::` |
| 4 | `04-ownership.keel` | **сердце языка**: перемещение, заимствование, пути, `mut`-контракты, group borrowing, затенение, анализ выхода |
| 5 | `05-modules.keel` | модули: файл = модуль, плоские имена, правила импорта |
| 6 | `06-practice.keel` | телефонная книга — всё вместе |
| 7 | `07-errors.keel` | что говорят ошибки компилятора и почему |

Если вы читаете только один файл — читайте `04-ownership.keel`.
Остальное знакомо всякому, кто писал на C или Rust; модель владения
— то, ради чего язык существует.

## С чего начать

- **Пишете на C или Rust** — начните с `01`, но не пропускайте `04`.
- **Пишете на Python или Java** — читайте всё по порядку: синтаксис
  другой, а `04` покажет главное отличие от Java (в Java объект —
  всегда ссылка; в Keel параметр без `&` — перемещение).
- **Хотите сразу код** — `06-practice.keel`, а потом вернитесь к `04`.

## Шпаргалка по синтаксису

```keel
// Объявление: тип ПОСЛЕ имени, без двоеточия
let x int = 5;
let mut y string = "можно менять";

// Константа: уровень файла, подстановка при компиляции
const MAX = 100;

// Функция: тип возврата после скобок; нет возврата — тип не пишется
fn add(a int, b int) int { return a + b; }
fn greet(name string) { println("Привет, ", name); }

// Структура и конструктор
struct User { name string; age int; }
let u User = User("John", 26);

// Методы
impl User {
    fn get_name(self &User) string { return self.name; }
    fn rename(self &User, n string) mut(self) { self.name = n; }
}

// Массив: размер — часть типа
let a [int; 3] = [1, 2, 3];
println(len(a));

// Ссылка и мутация
fn observe(u &User) { println(u.name); }        // смотрит
fn take(u User) { }                              // забирает насовсем
fn reset(a &[int; 3]) mut(a[]) { a[0] = 0; }    // меняет элементы

// Циклы
for i in 0..3 { }                  // 0, 1, 2 — правая граница не входит
for u in users { }                 // по значениям
while x < 3 { }
do { } while x > 0;

// Модули: файл = модуль, имена плоские
import "user.keel";
```

## Чего в языке пока нет

Проверено компилятором — каждое из этого не работает.

**Ближайшее** (волна 7 в `docs/lang-design.md`):

| | |
|---|---|
| `read_line()` | ввод из консоли — программа не может принять данные |
| `argv` | аргументы командной строки |
| имя файла в ошибке | сейчас «строка 4» без файла: при трёх файлах непонятно, где искать |
| `pub` | приватность модулей — сейчас всё видно всем |

**Дальше** (волна 8):

| | |
|---|---|
| `Vec<T>` | растущий список; массивы только фиксированные |
| `Option` / `Result` | «значение или ничего»; сейчас ошибки через `-1` и пустую строку |
| файлы | `open` / `read` / `write` |

**Крупное** (волны 1–6):

| | |
|---|---|
| `enum` + `match` | варианты «или-или» и их разбор |
| `f64` | дробные числа; сейчас деление целочисленное |
| кортежи | `(1, "два")` |
| замыкания | `fn(x int) int { ... }` как значение |
| дженерики | `Vec<int>`, `Map<string, User>` |
| трейты | общие наборы операций |

**Нет и не будет** (сознательно):

| | |
|---|---|
| lifetime-аннотации `'a` | вместо них group borrowing — пути |
| отдельный `&mut` | право записи даёт `mut`-контракт |
| отдельный `*` | разыменование автоматическое |

## Известные ограничения

Это не «ещё не сделано», а осознанные решения — они записаны
в `docs/lang-design.md`.

- **`len` строки — в байтах, не в символах.** Строки UTF-8, `strlen`
  считает байты: `len("Привет")` даёт `12`, а не `6`. То же поведение
  у `strlen` в C и `String::len()` в Rust.
- **Память при конкатенации не освобождается.** `"a" + "b"` берёт
  буфер из кучи, `free` для него нет — в языке нет владения для кучи.
  Для коротких программ незаметно; освобождение — волна 8.
- **`&int` нельзя изменить напрямую.** `x = 5` внутри `fn f(x &int)`
  пытается заменить саму ссылку, а не значение; символа `*` в языке
  нет. Меняйте через структуру или массив — там путь называет поле
  или элемент.
- **Объявления без инициализатора нет.** `let a [int; 3];` — ошибка.
  Массив заполняется явным литералом, как в `06-practice.keel`.
- **Нет `break` с меткой.** `break` выходит только из своего цикла;
  для выхода из вложенных — флаг.
